# 工资参数主管审核与版本发布

用户确认：真实数据由HR录入，其主管审核；开发阶段由智能体生成虚构资料。不得据此读取真实工资、迁移真实名单或发布生产。

## 业务与权限

- HR经办须有对应主体payroll_edit；岗位名称或HR角色不自动授予工资权限。
- 提交时以HRM当前直属主管分配唯一审核人，冻结提交快照并禁止自审。缺主管、主管不可用或关系变化均不自动改派/放行，HR可撤回重提。
- 审核人的权利仅来自该条明确分配的申请，限定主体、参数版本及有效直属关系，不扩成工资列表、标准全集、导出或核算权限。系统管理员不代审。
- 工资标准和主体规则均走草稿→待审核→通过发布/退回。旧activate接口不能绕过；已发布的受管版本不得直接停用以恢复旧值。
- 新版显式关联前版，原版内容/生效日期不改写；按生效日期取有效链末端。未来版不提前影响旧日期，新版到期不自动复活前版。同生效日的修订须版本号更高；早于已发布末端的生效日先阻断，避免隐式重排时间线。
- 草稿和未通过版本不参与核算；已锁定工资保持原快照，审批中的工资因有效来源变化而暂停，退回后重算。日期/工资规则未定项不补默认值。
