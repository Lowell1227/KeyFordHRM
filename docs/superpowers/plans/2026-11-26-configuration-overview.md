# 配置总览与业务缺项指引实施计划

**目标**　配置、验证、启用分别可见，业务页面从缺项提示直达正确设置。

**设计**　系统概览优先展示真实状态，完整能力说明仍可展开。沿用现有 AI 配置与业务权限，部署配置通过只读摘要和精确帮助展示。指引使用项目内预定义地址，在新标签打开，保留当前业务草稿。

1. 在 `api/src/system-configuration.controller.ts` 通过只读管理接口提供白名单状态。先验证缺项、已填未验证、权限、凭据不外泄。复用当前 AI 服务和通知状态。
2. 扩展 `SystemOverviewView.vue` 与 AI 服务配置页，增加优先处理、按域显示、配置与功能开关区分、已验证时间及直达设置。为部署配置保留实际读取结果与办理指引。
3. 在招聘、薪酬、绩效和组织等已识别业务缺项中接入统一的安全链接。有权用户直达设置，无配置权时直达同项说明。按已知业务状态接线，普通失败仍保留自身处理方式。
4. 运行定向回归、全量 API 风险检查、API/Web 类型和构建、桌面和手机页面检查。检查密钥从摘要到页面与帮助入口的权限，保留并行预览和线上版本。
