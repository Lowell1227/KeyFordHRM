# 周期安全终止与入口整理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 本计划由项目经理集成并统一验证，前端两个不重叠工作包并行。

**Goal:** 将目标台账、目标变更提升至绩效任务同级；常用入口置顶并按既有资格补齐经办入口；以影响预览、明确提交、独立授权和审计安全终止本周期未完成任务。

**Architecture:** 复用现有Vue页面、路由资格、绩效生命周期策略与数据库围栏。周期保留业务status，新增终止元数据；终止事务锁定评分期、任务及周期后重读权限和影响版本，任务及未生效目标变更保持历史，只取消未发送的关联提醒，不调用外部服务。

**Tech Stack:** Vue3/Element Plus、NestJS、Prisma/PostgreSQL、Node/Jest及Playwright。

**Spec:** 本会话2026-11-27用户确认的保护方案及本文件“业务约束”。

## 业务约束

- 初始只开发/隔离预览，沿用0.9.3。随后已核对原始用户追加授权：与工作台提速一起合并验收上线；正式不办理真实周期，仅给指定两位HR追加独立能力，发布四类状态另记。
- 首批正式授权对象为用户明确指定的两位现有HR账号；姓名不写进代码/迁移/公开夹具。本轮用虚构角色，正式配置按账号唯一标识、可审计授权办理。
- 新能力`cycle_terminate`仅显式配置授予，不因HR或管理员角色隐含获得，不附送删除权限；管理数据范围沿用既有周期范围。
- 终止不等于删除/暂停/重算。未完结可终止记录只读，已审批/确认/公示/豁免等受保护事实保留，未完成目标变更同事务停止。其他周期、入离职、转正、改进计划与工资记录不随同终止。
- 终止前完整展示任务清单、受保护结果、提醒与变更数量，原因必填、二次确认；影响版本发生变化必须409并保留填写内容。
- 终止后工作台对应待办消失，目标台账为同一任务标记已终止并可查历史；没有自动删除或整周期恢复入口。员工正在编辑遇失效必须保留本地输入并说明原因。
- 原绩效待办三级菜单/办理流程不改。菜单显示按原台账/目标变更资格，快捷入口按原路由权限及主体授权，不做个人硬编码或扩权。

## Review Focus

- 终止与员工提交/审批并发，锁后重新读影响版本，不可部分成功或覆盖刚完成结果。
- 终止排队期间撤权/停用，事务内复核；窄管理者不能操作其他人的周期。
- 终止后自动发起/补建任务及阶段推进不得重启该周期；保护结果的公示/申诉保持原路径。
- 后台任务失效时保留页面未保存内容；错误/空态不能假报成功或丢原因。
- PC/手机层级、快捷入口、权限边界一致；预览不复制真实资料或授予真实账号权限。
