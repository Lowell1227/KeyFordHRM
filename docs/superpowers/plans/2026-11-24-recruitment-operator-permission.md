# 招聘经办最小授权计划

目标：用户确认由两位指定经办创建、提交招聘流程，原负责人独立确认录用；不开发自审或转交功能。当前一位经办已有档案编辑，另一位只有招聘查看，不能把口头分工写成已可操作。

架构：沿用HrCapability和现有招聘流程，新增`recruitment_edit`（招聘经办），与档案维护、删除/转发/整表导出、录用确认分开。保持现有`canWriteRecruitment`旧管理边界，新`canEditRecruitment`用于日常资料/简历/跟进/应聘/面试办理；录用确认及反馈退回保持原资格。不修改数据库结构。

## 最小边界

- 新经办可创建/编辑人才、简历解析/上传、跟进、应聘及面试，提交录用及记录候选人答复；可作为应聘负责人。读取包含本人职责需要的共享资料。
- 不新增人才删除、转发/分享管理、整表导出、入离职/档案办理、组织维护、审核他人面试反馈或录用确认资格；旧有档案管理能力不收回。
- 真实账号只在私有生产授权和原审计中维护；仅对当前缺少招聘经办能力的指定账号按差集增加一项，不给其他查看者加权，不改系统角色。
- 候选人接受录用后，仍交有原人事档案经办能力的人员办理入职。原负责人本人提交仍不能自审。
