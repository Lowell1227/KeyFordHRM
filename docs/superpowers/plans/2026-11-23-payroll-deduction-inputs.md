# 扣缴资料维护与审核接线 A2.1

**Goal:** 将代码虚构参数之外的HR可维护扣缴资料接入既有主管参数审核和实发试算，使用隔离虚构数据，不冒充A2正式累计账本或A3最终导出完成。

**Architecture:** 新增按主体/员工/发薪日的扣缴资料版本，复用PayrollParameterRelease主管分配/回避/快照/并发。复用A1计算器，gross只从工资批次冻结明细取得，客户端不能覆盖。现有complete/missing虚构演示不变，新增saved模式仅读已审核匹配版本；无资料/草稿/错日/无依据时待配置，不回退示例金额。

**Spec:** 需求0.13与正式准备清单，既有扣缴基础计划A2分阶段落实；用户确认真实数据HR录入、其主管审核、开发先造数据并要求继续。

**Constraints:** 正式域/生产继续关闭；只迁移hrm_preview，保留真实身份/业务记录。不内置法定税率、居民身份、月费用、缴费参数或工资数据。已批准参数不可改写，当前试算不生成实际已扣、实际付款、自动累计或正式批准实发。
