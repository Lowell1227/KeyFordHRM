# 实发核算闭环实施

本轮承接用户“把剩余重点开发完”：A2实际扣缴累计与更正、A3实发复核审批与最终Excel作为一个闭环交付。只使用隔离虚构数据，生产开关、真实工资和正式授权不动。

## 契约

- 复用工资批次、版本、复核审批及主体授权；版本增加明确发薪日和完整实发快照，不另建审批流。
- 已审核扣缴资料可维护累计基准日、基准前累计、本月累计扣除额度和个人缴费目标。实际账本只追加明确确认的实发及扣缴事实，审批和导出不写已付。
- 同一人员同一税年最多一个未结实发安排；同月扣除和同缴费月个人缴费按目标减已确认事实计算。资料/累计变化使未付款版本失效，退回或撤回后重算并重新审批。
- 更正通过新审核参数和新批次差额追加，不覆盖已批准/已付。负扣缴或负实发需人工核对，不自动退款、追回或当零。
- 实发确认按整个人员行办理，确认日须与批准发薪日一致，同时原子记录五项应发结算与扣缴事实；改日先作废未付版本重算，幂等重试不重复入账。
- 试算不能提交或导出；隔离验证表带测试标识；正式导出必须正式开关、主体独立权限、完整实发快照、全部审批和下载前后复查均通过。
