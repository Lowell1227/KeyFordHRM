# 花名册按模块导出

## 本轮要求

以用户提供的《孚德新花名册20260924.xlsx》表头结构为参考，补齐可维护档案字段的导出，允许按模块批量选择。弹窗仅提示“预计导出 N 条记录”，删除重复范围和跨页说明。

## 实现口径

- 原表 `在职整理!A1:CH2` 为 86 列、两行表头。保留姓名、工号优先的字段顺序，使用分组表头、橙色表头、微软雅黑、边框、换行、合适列宽、冻结表头及身份列、完整筛选范围。
- 模块为基本与任职、个人与教育、身份与联系、社保公积金、银行信息、最新合同、合同历史、系统信息。模块支持全选、取消和半选，字段可单独选择，全局保留全选/清空。
- 字段目录由 API 按当前用户已有能力提供，导出再次校验。默认保留原来的九项；新档案列仅档案维护/审核能力及现有管理员可见。仅组织维护能力仍限原十项。
- 身份证和银行卡只导出录入状态，不增加明文读取权限。不导出密文、指纹、原始导入证据、未提交草稿或附件链接。不添加没有正式字段支持的考勤列、辅助列。
- 最新合同与档案详情使用相同排序；合同历史为独立工作表，每份历史合同一行，包含员工身份、合同日期与主体、停用状态。不限续签或转签次数，不因展示重排合同编号。
- 仍使用已执行查询的人员范围和 5000 人上限；不会把尚未点击查询的输入用于导出。日期为可排序的 Excel 日期，工号等标识为文本，缺失数据留空。
- 保留导出审计，记录字段键、实际人数及非文本筛选范围，不记录搜索文本或导出内容。
