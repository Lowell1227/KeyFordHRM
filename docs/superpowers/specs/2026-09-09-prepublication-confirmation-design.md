# 公示前员工确认与异议重评

## 已确认业务

用户确认主流程改为：直属上级周期评定 → 部门复核（同人合并）→ 绩效校准 → 冻结结果审批人审批 → 员工确认 → HR 公示。

用户后续确认：员工在结果确认页可选择“确认结果”或“不同意”。不同意须填写异议原因，直接退回冻结的绩效直属上级重新评定，不经过 HR 分派；沿原有部门复核、校准、分管总审批链路回到员工确认。HR 仍可代录公示前的线下申诉。未确认或正在重新评定的结果不可公示，其他已确认员工可独立公示。

## 状态与兼容

- 沿用既有状态与时间字段，无数据库迁移或历史批量回填。`approval` 且有 `approvedAt` 表示待员工确认；`confirmed` 且未公示表示已确认待公示；发布后是 `published` 且保留确认时间。
- 历史已公示但未确认的记录继续允许员工确认；历史公示/确认时间和结果不改写。
- 员工在审批通过后可查看本人的结果，仍使用既有可见字段设置；不开放其他员工的结果。报表和已公示统计必须以实际发布事实为准，不能将公示前确认误算为公示。
- HR 代录申诉只选择已审批、未公示、有冻结直属上级且无未完成申诉的任务。事务锁定任务，记录申诉原因和原结果快照，撤销本轮确认、审批、校准、复核有效标记，退回 `manager_scoring`；保留原月度评分、评语、审批及操作历史。
- 新申诉全程只读跟踪原评定链路，HR 不直接改等级。重新审批后再次由员工确认；确认时结束对应的新申诉，发布仍要求确认和没有未完成申诉。
- 员工只可对本人已审批、尚未确认且未公示的结果提出异议。与确认、HR 代录申诉、公示共用任务行锁；确认后、已公示、豁免、未审批及重复请求不得退回。若重评已再次审批通过，员工仍不同意，可在同一未完成申诉下追加原因继续重评，保留每轮历史。
- 直属上级查看异议原因并重新评定周期等级、评语；原月度评分和说明不变，周期得分仍按月份平均。异议产生直属上级站内待办，HR 可在既有申诉页面跟踪，无新的钉钉发送行为。
- 历史旧申诉保持可查询，既有已公示申诉处理不在本次重定义范围内；新流程记录不得调用旧的直接改判接口。

## 页面与接口契约

- 员工待办和结果页显示“待确认结果”“已确认，待公示”“已公示”；本人在公示前待确认时可“确认结果”或“不同意”，历史已公示待确认记录只保留确认入口。
- 四类结果列表及公共详情使用同一状态表达，保留办理记录。HR 申诉页显示“录入申诉”，候选条件为公示前；新申诉详情展示当前环节和关键节点意见，已进入流转的记录无直接改判按钮。
- API 增加 `GET /appeals/candidates`，参数 `cycleId?`, `keyword?`, `page`, `pageSize`，返回 `{ items, total, page, pageSize }`，候选项含 `id`, `employeeName`, `employeeNo`, `deptName`, `cycleName`, `status`, `approvedAt`。
- 申诉列表/详情新增 `workflowType: 'prepublication' | 'legacy'`、`taskStatus`、`approvedAt`、`employeeConfirmedAt`、`publishedAt`、`canResolve`；新申诉 `canResolve=false`，历史旧申诉按原规则。
- `POST /tasks/:id/employee-disagree`：仅登录员工本人，正文 `{ reason: string }`（1～2000 字，去除空白后必填），返回 `{ id, status: 'manager_scoring' }`。员工入口不开放 HR 申诉后台列表或办理权限。
- 关键节点记录仅透传申诉来源 `employee` / `hr`，分别显示“员工提出异议”/“HR 发起申诉”，不向公共历史中透传内部原结果快照。
- 公示状态新增 `pending_confirmation`（待员工确认），`ready_to_publish` 仅限确认后。
- 不新增系统角色或扩大人员管理权限。新增待办使用站内通知，不自动发钉钉；现有明确勾选发送公示通知行为保留。

## 验证与发布

使用隔离测试数据验证审批→员工确认→公示，以及员工直接异议、HR 代录申诉→上级重评→审批→员工确认→公示；验证越权、并发重复提交、反复异议、旧结果失效、公示阻断、月度数据不变及历史兼容。同一未完成申诉的原结果始终取首次快照，结案的“维持／改判”也以该快照为基准，各轮意见保留在历史中。API 全量测试和构建，Web 类型检查及 PC/390px Playwright。禁止修改真实员工结果和发测试钉钉消息。合并前保留其他任务的新基线，发布 API/Web 并保留可回滚镜像，执行外部只读核验。
