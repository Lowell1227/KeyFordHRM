# 花名册精简默认字段与银行卡加密导出

- 用户选择本轮只处理导出和favicon；登录页孚德E-HR、轮播及人才标签暂缓。保留现有招聘工作，不提交其他修改、不发布生产。
- 档案导出默认9项：姓名、工号、所属公司、一级/二级/三级部门、岗位、入职日期、任职状态。合同及其余字段按需选择。组织维护权限可见字段不扩大，其旧默认列保留。
- 银行信息增加银行卡号，默认不选。身份证和银行卡号任一选中须当前账号验密及独立4至64位Excel打开密码；复用既有POST、AES-GCM资料解密、Office加密、限流及审计，不引入第二条安全路径。
- 按实际选择读取/解密敏感列；普通GET拒绝两类字段，银行卡号单选不读取身份证密文。未知密文损坏拒绝返回文件，号码以文本保留前导零。审计不保存明文或密码，不修改账号。
- favicon使用既有品牌图生成真正ICO静态文件，保留现有PNG声明，直接请求/favicon.ico也返回图标。
- 取舍：扩展既有导出最小且规则一致；不新建单独银行卡接口或添加下载后再加密步骤。真实角色权限不扩张、正式个人资料不读写。
- 验收：API字段和真实HTTP边界、加密/解密、默认列及普通导出回归；隔离预览PC/手机下载、输入清理、只选银行卡及两种同时导出；favicon有效ICO/200，正式构建含该资源。
