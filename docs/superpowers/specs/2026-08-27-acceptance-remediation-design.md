# 验收问题集中整改设计

## 状态与约束

- 日期：2026-08-27
- 状态：用户已要求跳过界面草图并直接在 `main` 实施、上线。
- 数据主源：人员与组织以 HRM/花名册为准；钉钉仅用于登录和身份绑定。
- 发布：保留最新线上基线与回滚镜像，只替换本次确有变化的 API/Web。
- 验证：每块改动先写一个聚焦失败用例；最终只做一轮聚焦验收、类型检查和生产构建，不循环运行全量测试。

## 1. 密码登录

1. 登录入口标题改成“密码登录”，账号为工号，初始密码为 `0000`。
2. 上线数据迁移将所有 `accountType=employee` 且未删除、未离职的员工密码统一重置为 `0000`，并置为需要首次改密；测试和服务账号不处理。
3. 仅使用密码登录时执行强制改密。钉钉登录不拦截。
4. 新密码为 4–6 位数字、两次一致，且不能继续使用 `0000`。
5. 人员设置提供“一键重置为 0000”；下次密码登录重新强制改密。
6. 修改和重置均写审计，不记录明文。

## 2. 人员、试用期与组织

1. 试用期与转正六个现有入口整体移动到绩效模块，路由、流程、数据和角色权限不变。
2. 员工档案改为分区编辑页，覆盖账号基本信息、个人教育、联系住址、社保公积金、银行、当前任职、任职历史、合同协议等已有可维护字段；年龄、司龄等派生值只读。
3. 档案编辑提交后生成待审核版本，审核通过才事务性写入正式档案、任职记录、合同记录和 `User` 当前投影；驳回不改变正式值。
4. “员工档案编辑”和“员工档案审核”是两项独立能力，可授予同一人或不同人；同一人兼具两项能力时允许审核本人提交的请求，两个动作仍独立留痕。
5. 敏感字段默认遮罩，编辑时只在填写新值时替换；请求、日志和审核列表不展示身份证或银行账号明文。
6. 组织编辑能力允许改部门名称和通过长按拖拽改变父子层级。拖动前校验不能移入自身或后代；确认后同步重算该节点及全部后代 `fullPath`，部门 `id` 和员工归属不变。
7. 花名册导入弹窗提供固定 `.xlsx` 模板下载。模板列与当前解析器一致，包含填写说明、必填提示和示例行；上传仍先预检再审核。

## 3. 系统权限

1. 系统权限增加“普通 HR”，现有 `hr` 对外显示“HR 管理员”，`system_admin` 不变。
2. HR 管理员默认具备 HR 全部管理能力；普通 HR 只拥有明确授予的能力。
3. 能力至少包括：`employee_archive_edit`、`employee_archive_review`、`organization_edit`、`cycle_plan_edit`、`cycle_plan_review`。
4. 迁移按当前 HR 部门和唯一姓名设置：姚遥为 HR 管理员；其他人事部在职员工为普通 HR；余焱玲获得档案编辑和组织编辑；方园获得周期计划创建编辑。若姓名或部门匹配不唯一，迁移应停止而不是静默赋权。
5. 账号设置页可以查看和修改普通 HR 的能力组合；系统管理员可维护系统权限与能力。

## 4. 绩效周期与计划

1. 创建表单不再选择“HR 负责人”。创建人由当前账号自动写入，只在表单底部和详情辅助信息中显示。
2. 新增审核人，候选人为在职 HR 管理员；新建或关键字段编辑后状态为待审核，审核通过后才能发起。
3. 有 `cycle_plan_edit` 能力的普通 HR 可创建编辑；有 `cycle_plan_review` 能力的账号可审核；允许同一账号兼具两项能力。
4. 季度、半年度、年度周期增加“需要月度跟进”开关；开启后在周期和目标跟进页明确显示每月更新要求。月度周期不显示该开关。
   - 2026-08-29 变更：新建流程不再保留独立月度跟进开关，改为“每月复盘并评分”单一配置；已审核、已发起或进行中的历史周期仍按原配置执行。详见[月度复盘与评分一体化设计](./2026-08-29-unified-monthly-review-and-scoring-design.md)。
5. 创建、保存、审核和发起均不加载或校验考核模板。发起时为参与员工创建空白任务，模板快照允许为空。
6. 周期详情数据漏斗中的人数数字统一带“人”单位。

## 5. 员工目标制定与指标库

1. 发起后的员工目标制定默认空白，不带考核模板和指标库内容。
2. 编辑行只保留“名称、描述、标准、权重”。
3. 保存时只校验：至少一条有效目标、名称去空格后不重复、权重合计不超过 100%。不要求保存时等于 100%。
4. 提供“保存”和“保存并添加下一个”；后者保存成功后追加并聚焦一条空白目标。
5. 指标库从导航、路由和目标制定引用入口中移除；历史指标库表和历史外键不做破坏性删除。
6. 考核模板模块暂时保留用于历史查看，但不参与周期创建、发起或员工目标制定。

## 6. 验收

- 密码：真实员工用 `0000` 登录后只能改密，4–6 位数字通过，`0000`/不一致被拒；钉钉登录不拦截；管理员重置后再次触发。
- 权限：姚遥、余焱玲、方园分别看到并完成被授权动作；普通员工及无能力普通 HR 的菜单和直达接口均被拒。
- 档案：编辑覆盖全部分区，提交前正式值不变，审核后任职/合同/投影同步，敏感值不出现在列表和日志。
- 组织：改名和拖拽后树、后代路径、员工归属一致；自环和移动到后代被拒。
- 周期：创建人自动记录、审核后才可发起、月度跟进标识可见、没有模板也能发起空白目标任务。
- 目标：只显示四字段，两个保存按钮可用，重复名称或总权重超过 100% 被拒。
