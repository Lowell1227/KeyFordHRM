# 绩效待办表单统一布局设计

## 目标

统一员工目标制定/确认、主管目标审核、员工月度跟进、主管评分四类高频表单的页面骨架，降低角色切换和环节切换时的学习成本；不改变现有接口、权限和业务状态流转。

## 统一骨架

- 顶部继续展示考核周期、人员身份、当前状态和截止时间。
- 主内容采用同一个 `PerformanceFormWorkspace`：左侧为当前任务表单，右侧为参考信息或操作记录。
- 桌面端右栏宽度保持 300–360px；小于 1100px 时改为单列；手机端辅助信息可折叠。
- 页面底部操作区统一为“左侧完成进度/说明，右侧操作按钮”，按钮文案与当前角色动作一致。
- 右栏只放辅助判断信息，不承载提交、通过、退回等主操作。

## 四类表单

1. 员工目标制定/确认：左侧填写或确认目标；右侧使用“参考信息”，包含“对齐目标”和“操作记录”。
2. 主管目标审核：左侧审核员工本次提交的目标；右侧使用“参考信息”，包含“参考目标”和“操作记录”；退回原因只出现在操作记录中。
3. 员工月度跟进：左侧填写进度、完成状态、自评分和说明；右侧展示当前指标参考信息。
4. 主管评分：左侧查看员工跟进结果并评分；右侧展示当前指标参考信息。

## 术语

- 统一使用：目标制定、目标确认、目标审核、月度跟进、主管评分、参考信息、操作记录、退回原因。
- “流程历史”统一改为“操作记录”。
- 月度场景不再混用“复盘与评分”“复盘与自评”“提交复盘”，统一为“月度跟进”；整周期场景使用“周期跟进”。
- 内部路由键、接口字段和数据库枚举不改名。

## 验收

- 四类表单均使用同一个桌面双栏/窄屏单栏布局规则。
- 主管目标审核的操作记录位于右栏，不夹在指标和审核操作之间。
- 员工目标制定不再同时出现参考信息抽屉和右栏。
- 关键操作、权限、保存与提交行为保持不变。
- PC、窄屏和手机契约测试通过。
