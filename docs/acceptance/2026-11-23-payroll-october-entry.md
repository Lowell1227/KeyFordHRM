## 当前应怎样办理

1. 经办从已确认公司、2026-10的工资资料深链进入“工资规则”，明确实际发薪人员、日历及规则；冲突人员先交HR核对，不能自动归到本主体或自动忽略。
2. 工资标准、规则及扣缴资料提交后，由经办人在HRM中的直属主管审核。这不是工资复核/审批角色，不给主管默认附加工资全量权限。
3. 已审人员和规则就绪后，经办同步本月钉钉考勤、核对异常并封账。真实个人/终审接口权限与覆盖仍须实际验证，考勤组成功不当成个人成功。
4. 建立“真实资料对账”，核到税后实发；由已指定工资复核人、审批人办理首月签收，再从签收首月办理正式工资。最终下载及实发登记须全部审批通过，10月对账本身不能导出正式工资或支付。
