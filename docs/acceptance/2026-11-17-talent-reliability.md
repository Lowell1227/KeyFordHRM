| 问题 | 修改与验收要点 |

| 系统概览能力说明过时 | 人才库与简单邀约标为已提供，完整招聘与 Offer 仍待建设；注明是能力建设清单，不是实时健康监测 |

## 保留与限制

- 原8来源、10标签、文件数量/大小、分享5人和7/30天是已确认MVP约束，本次不泛化为配置中心。
- 旧手动转员工接口保留明确业务错误，不能绕过入职办理和确认到岗；历史绩效关系不回写。合同和花名册旧数据不顺带清洗。
- 分享原件默认关闭；开启会让指定接收人看到原文件内容，原件可能含联系方式，脱敏摘要不等于原件脱敏。
- 已知 Web Node 全量历史27项债务见上一轮同步发布记录，本轮未把它们标成通过，也未为本任务重复全项目Web测试。
- 旧页面无编辑基准会拒绝保存，需要重新打开最新页面；不会静默覆盖。
- 当前面试通知为系统内通知。钉钉日程仍关闭，不把成功写入通知当作真人已阅读或第三方已送达。
