# 人员档案审核优化：发布候选验收

## 范围与边界

- 修复个人信息免审字段在自动保存草稿后提交发生版本冲突，以及提交后详情未及时刷新。
- 免审值更新时同步待审申请的基线和提案，保留修订历史；同字段存在不同待审提案时回滚并提示冲突。
- 日期严格校验，个人信息操作审计中的手机号、地址和紧急联系人脱敏。
- 完善宽松模式：仅系统管理员可切换，缺省为标准模式；不扩大提交或手工审核权限。
- 自动审核仅作用于开启后新提交的申请，失败保留待审，未来任职及入职仍按生效日期处理。
- 单独重提绩效上级关系只审批关系部分，不连带批准同一申请中的旧档案提案；该路径已完成真实数据库红绿回归。
- 按用户确认，部门合并始终人工审核，本次不更改其生效与任职历史规则。
- 不包含人才库、文件上传扩展等其他工作区改动；不修改数据库结构、真实员工或考核结果。
- 上线不替用户开启宽松模式，产品版本保持 0.8。

## 业务验收清单

1. 标准模式下编辑员工学历等免审字段，等待草稿保存后提交，确认立即显示新值且无 409。
2. 同时修改免审与需审字段，确认仅免审部分立即生效，其余进入待审。
3. 管理员进入“系统管理 -> 系统概览”，确认默认仍为标准模式；取消开启不改变配置。
4. 仅在业务明确允许后开启宽松模式，验证新提交申请的实际结果、审计记录和未来生效日期，然后按需要恢复标准模式。
5. 宽松模式下部门合并仍进入人工审核，既有待审申请不自动审批。

## 保留风险

- 部门合并旧逻辑的任职历史联动问题另行评审，本次未修复，也不自动审批合并。
- 岗位人工审核的能力点与历史角色校验不一致仍需专项确认，本次未扩大权限。
