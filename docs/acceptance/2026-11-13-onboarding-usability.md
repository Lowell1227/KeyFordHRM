覆盖的真实页面流程：

- 直接办理入职 → 自动暂存 → 关闭 → 草稿续填 → 必填校验 → 提交 → 办理详情 → 审核 → 确认到岗 → 查看档案。
- 同一虚构员工离职审核 → 归档 → 主入口按姓名找到历史人员并明确选择 → 再入职 → 审核 → 确认到岗。同一员工 ID、新工号，原工号及任职历史保留，归档状态解除。
- 人才入库 → 跟进 → 页面创建/修改/结束面试 → 人才转入职 → 审核 → 到岗 → 精确档案 → 离职 → 归档。
- 退回重提、取消恢复后重新审核、快速重复提交只产生一份申请、同名离职人员范围与明确选择、普通员工不能访问人员维护。
- 所有办理动作通过页面发起；API GET 只用于结果断言。测试记录未发现浏览器未捕获异常或预览域之外的页面请求。没有用 API 写入绕过页面选人/审核。

## 试用步骤

1. 打开固定预览，使用预览 HR 身份登录，进入“入离职 → 办理入职”。只填虚构资料。
2. 填姓名、部门、入职日期；补充资料按需填写。可关闭后从“草稿 → 继续编辑”检查续填位置。
3. 点击“提交”，应直接进入本人的办理详情；审核通过后仍是待入职，点击“确认到岗”后才生效。
4. 生效详情点击“查看员工档案”。再入职仍从“办理入职”输入历史人员姓名，核对工号/部门并明确选择。
5. 对已审核、待到岗的虚构申请，在时间轴的“确认到岗”面板修改日期并重新提交；重审后应在同一时间轴看到历次修改及审核，当前操作仍位于到岗环节内。确认到岗后面板消失，保留操作人和生效记录。
