# 招聘经办与独立录用确认

## 本次业务决定

用户确认由指定的两位招聘经办创建、提交，原负责人独立确认录用。本期不新增确认人、自审例外或转交申请功能。不修改已有申请的提交人、阶段或历史。

原人员经办已有档案编辑可办理招聘；指定绩效经办只有招聘查看，不能仅口头确认“可以创建”。本次新增独立`recruitment_edit`（招聘经办），保留其原绩效/转正职责及此前收回的档案编辑、档案审核和组织维护边界。真实姓名/ID仅由受控生产授权与原审计记录维护。

## 权限边界

- 招聘经办：人才资料新增编辑、简历上传/解析、跟进、应聘及面试创建维护、提交录用、记录候选人答复；可选择自己为负责人。可读共享招聘资料。
- 仍不授予：人才删除、分享管理、整表导出、录用确认、退回他人面试反馈、人事档案/入离职及组织办理。候选人接受录用后交有原人事经办能力的人员办理入职。
- 面试选人复用HRM正式在职/试用人员事实，使用独立最小选择器，不为招聘经办放开通用员工档案；不使用钉钉通讯录覆盖。
- 参数与能力可由管理员维护，不在代码或迁移中写人员姓名，不改系统角色或其他能力，不默认授给全部招聘查看者。
