# 2026-11-17 合同管理操作优化

## 授权与业务范围

- 用户确认八项合同管理方案并明确要求开发后直接上线。本轮只改善员工档案合同维护，不重做花名册初始化，不编辑正式员工数据。
- 展示按上海业务日期分为待生效、期限内、已到期、待核实。无固定期限作为期限属性；当前期限内和未来合同同时可见，已到期记录默认折叠。
- 已移除及来源不能确定的旧版本单列历史保留记录。只有已应用变更的前后快照能证明移除时才标记已删除；记录停用时间不冒充劳动合同解除日期。
- 录入、续签、转签、补录、补充材料、修改、删除均在现有档案抽屉操作，一次展开一份；保存前可撤销删除。自动保存仅存草稿，显式“保存并生效”沿用既有直接应用与审计，不增加人工审核。
- 转签选择新签约公司后同步合同的新公司名称，保留原公司。不会自动更改员工所属公司或旧合同日期；日期重叠仅提醒。
- 旧草稿含其他档案修改时恢复完整编辑，明确显示将一起提交；脱敏身份证号和银行卡号也依据变更字段判断，不因两边均已配置而隐藏变更。提示只显示字段名。
- 导出范围、字段键及权限不变。单份摘要模块改称“最新合同”，其余明细工作表改称“其他合同记录”，避免将未来最新记录误称当前履行合同。
