# 合同子表修复与验收

日期：2026-11-14，北京时间。产品版本保持 0.8。前置审查见 [合同专项审查](2026-11-13-contract-management-audit.md)。

## 用户确认口径

- 只分当前合同和历史合同，历史默认折叠。当前合同可以待生效，不单列未来合同类别。
- 当前主合同按明确的生效日期优先、日期倒序选取；均缺生效日期时才参考签订日期，不补造旧日期。附件、保密协议或移除记录不抢占当前主合同。
- 类型统一为首签、续签、转签；合同名称仍保留劳动合同等实际名称。
- Excel 对已有档案权限者默认勾选当前合同，不默认导出历史工作表；历史可按需勾选，原员工筛选与权限边界不变。
- 用户已授权本轮上线。历史数据清理不包含在内；不改真实合同内容、不重新导入、不合并或删除存量记录。

## 修复对照

| 问题 | 本轮处理 | 边界 |
| --- | --- | --- |
| 补签日期压过后续转签 | 前后端统一生效日期优先；缺生效日期的旧合同不覆盖日期明确的新合同 | 保留原签订、到期日期；同日按既有创建时间/ID稳定排序 |
| 当前/未来/历史概念混淆 | 当前/历史两组，日期状态显示待生效、正常、已到期、期限待补等 | 日期状态不等同于法律效力判断；记录停用显示旧版本/已移除 |
| 页面类型与导出不一致 | 两个表单、档案详情、变更对照统一三个业务类型 | 旧非主合同类型保留可读，不强制改写 |
| 新增相同内容但序号不同 | 显式提交及应用事务校验内容，重复定位合同名称 | 保留ID/并发校验；存量重复未变化时不阻断无关提交 |
| 非法日期、起止倒置 | 新建/实质修改校验真实日历及到期不早于生效 | 允许补签晚于生效；不修改通用 nullableDate 或历史初始化 |
| 合法合同从页面提交却报格式错误 | DTO 明确保留合同对象行，修复隐式类型转换把对象变成数组 | 保留非法行、日期、重复内容及权限校验 |
| 上传尚未完成/失败却提交 | 两入口共用上传任务状态，阻止提交；数量计入在途文件，支持重试/移除，隔离迟到回调 | 草稿不是正式生效；已有附件权限及后端校验不放宽 |
| 误移除、记录难核对 | 正式记录待移除可撤销；新增空行直接移除；摘要复用既有差异逻辑，展示具体日期及材料名称 | 沿用原提交与审计，不新增合同审批 |
| 历史重复显示/导出 | 默认仅展示/导出当前，历史折叠及按需导出，旧版本标记更明确 | 正式跨批次重复仍保留；这不是历史数据去重完成 |

## 真实预览与发布

固定入口：[员工档案预览](http://localhost:5173/users)。预览使用 `hrm_preview` 独立数据、独立文件桶和虚构身份，真实通知/日程关闭。

PC/手机真实后端业务验证 8/8 通过，0跳过、0重试、0不稳定，109.332秒。结果与虚构截图在 `test-results/contract-management-final/results.json` 及相邻目录。测试代码为 `web/e2e/preview/contract-management.spec.ts`，使用 `web/playwright.preview.config.ts`，不运行普通数据准备脚本。

每种尺寸分别覆盖：

1. 真实页面新增首签、再新增转签；补签签订日不能压过转签生效日。当前待生效、历史默认折叠，原签订/生效/到期日保留；默认和主动选择历史两份XLSX逐项回读。
2. 无关编辑保留虚构历史错误日期；新增非法/非闰年日期与起止倒置被就近拒绝，修改正确后真实提交，已到期状态正确。
3. 页面双击提交仅产生一次生效请求；再次新增内容完全相同的合同被400拒绝并定位名称，原记录不变。
4. 真实无效PDF上传返回400并阻断提交；移除失败任务后上传有效虚构PDF，提交重开，下载字节与原文件相同。

主会话检查了电脑/手机截图，字段、错误、抽屉及导出固定操作区无横向溢出。运行使用仅档案编辑能力的虚构普通HR，不替换后端接口，不从API绕过页面动作；范围仅本轮合同维护，不冒称完整入离职或原生Safari验收。

本节为预览验证记录；固定提交 `c7e92f19` 已于2026-11-14 07:07上线API/Web，外网健康、页面资源哈希及电脑/手机只读检查通过。固定提交、备份和回滚信息见 [发布记录](2026-11-14-contract-management-release.md)。业务验收仍待用户确认。

## 保留风险

- 生产历史重复存在字段差异和导入批次关系，必须另行只读核对、HR确认、备份并留痕后才能清理；本次没有改真实数据。
- 本次不修历史初始化器的序号匹配算法，不重跑历史批次。
- 自动化浏览器与 ExcelJS 回读不等于原生 Excel 或正式 HR 的人工业务验收；实际 Safari 和真实附件由业务继续确认。
- 关闭编辑/移除上传会丢弃迟到回调，但不会中止HTTP；未完成文件不随草稿持久化，重开后需重新选择。已展开日历时档案父容器切入忙碌态尚无独立专项测试。
