# 工作台薪酬待办汇总性能复测

2026-11-27，北京时间。独立工作树从 `dac6e53f` 起步，正式 API 对照为 `15367f7d`。昨天已发布的刷新、折叠和导航竞态修复生效，本次改动仅在后端汇总读取。项目经理另行办理的菜单、绩效导航和周期开发留在原工作树。

## 症状与修复

- 发布记录的隔离混合请求中，工作台汇总 p95 2.43 秒，超过 1.5 秒观察线。本轮用虚构数据复现，HR 样本总耗时由薪酬组主导。原汇总对每个授权主体单独读取批次，还调用完整的工资资料页面读取器，读取待审、已结束及历史比较。
- 汇总现在一次读取授权主体范围内当前待办需要的工资批次元数据，一次读取待审工资资料和经办人的有效主体授权。沿用独立复核、当前直属主管、有效经办权限、禁止自审及冻结批次办理人的判断。资料审核详情、工资审批、发薪、授权与配置入口仍由原模块办理。
