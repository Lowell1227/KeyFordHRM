# 目标变更与改进计划预览验收

## 范围

- 简历 AI 解析暂停，本轮只做绩效目标变更和改进计划。
- HR 按周期及员工开放目标变更；员工本人和该任务冻结的绩效直属上级均可发起。
- 允许修改、新增、删除目标；沿用原考核维度与计分规则。原维度中最后一项目标需用同维度新目标替换，不通过删目标隐式修改维度权重。
- 目标变更提交后走原目标审核链；审批通过前原目标仍生效。已提交过或已锁定的月份保留原版本及结果。
- 同任务仅一个进行中的申请；退回重提复用申请，HR可撤销，生效后消耗资格。再次变更需HR重新开放。
- 新改进计划使用：直属上级发起 → 员工确认 → 部门负责人确认 → HR确认 → 分管领导确认目标 → 员工自评 → 直属上级评价 → 部门负责人评价 → 分管领导确认结果。
- HR节点由HR管理员及同时具备 cycle_plan_edit、performance_publish 的绩效专员共享办理，一人确认。系统管理员、查看全局权限不自动取得HR审核资格。
- 旧V2计划不自动迁移；已离职、归档及缺失办理人的计划明确显示暂停原因，不修改真实计划状态。

## 试用入口

1. 打开 http://localhost:5173 ，选择虚构HR身份进入预览。
2. 绩效工作台 → 目标变更，HR选择周期、员工，开放变更。
3. 切换虚构员工或其冻结直属上级，发起变更，核对新旧目标并提交。
4. 各审批人按当前环节办理，最终核对已提交月份未变化。
5. 绩效运营 → 改进计划，由虚构直属上级创建，按九环节依次办理。

可反复试用的周期为“目标变更验收（虚构数据）”，员工为“测试·张辰”，直属上级为“测试·周强明”，分管领导为“测试·李弘”，HR为“测试·姚遥”。选择预览身份即可切换，不提供或展示密码。部门负责人兼任直属上级时自动跳过重复节点，这是既定规则。临时回归用例另建独立身份并清理，不与此样例混用。
