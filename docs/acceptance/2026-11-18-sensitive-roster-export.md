# 身份证号与加密Excel导出

## 已确认行为

- 用户选择：验证当前账号密码，并设置独立的Excel打开密码。
- 身份证号作为“身份与联系”中的可选字段，默认不选；只有已有档案维护/审核权限的HR及系统管理员可见并导出，不扩大组织维护权限或数据范围。
- 普通GET导出拒绝身份证字段；专用POST接口只从请求体接收密码，先验证当前登录人的账号状态、密码和权限，再读取身份证密文。未设密码或要求改密的账号提示先在个人中心设置/修改。
- 文件打开密码4至64位，前端重复输入，与账号密码不同。下载为Office Agile AES-256文件加密XLSX（SHA-512、100000次派生），不是工作表锁定；未选身份证的普通导出保持原行为。
- 身份证沿用现存AES-GCM加密资料解密，文本写入以保留前导零；资料损坏时拒绝导出，不能静默给空白或明文替代文件。
- 密码不进URL、浏览器持久存储或审计；取消勾选、关窗、成功/失败后清空。错误密码就近提示且不把操作人登出。敏感下载响应no-store/private。
- 每操作人15分钟最多5次密码尝试，成功重置；当前单API进程内同步预占计数防止并发绕过，Map数量有界。加密工作线程最多2个、60秒超时；加密完成/失败后清理原始Buffer。多副本部署前须把尝试计数迁至共享存储，不声称当前限制跨进程。
- 审计保留操作人、列名、条数、筛选及加密标记，不记录密码、明文身份证或姓名搜索词。只在文件生成/加密成功后创建成功审计；审计失败不返回文件。
