# 虚构扣缴试算预览验收

日期：2026-11-22。范围：S0必交付功能的共用开发增量，不是正式算薪启用。产品版本保持0.9.2。

## 业务与代码边界

- S1b公司名称由用户暂缓提供，留空；S1a仍为确认发薪主体的全部在职人员。不得由部门、账号或合同主体推断实际发薪归属。
- 在既有批次详情接入A1，使用服务端已核算的本批税前差额。只允许已登记虚构预览，逐主体检查payroll_edit；不接收客户端金额、人员或主体覆盖。
- 试算不保存配置、审批、工资、占用、付款或导出记录。界面明确“虚构试算 · 未纳入审批”，不是正式工资单，不把税前批准当作实发批准。
- 完整参数与缺项检查均为数学夹具，不能作为公司制度或法定参数。正式来源、扣缴累计账本、批准快照、正式实发导出和授权管理仍待交付及确认。

## 隔离样例与执行

- 专用脚本：`node scripts/prepare-payroll-deductions-preview.cjs`，先验证hrm预览容器、hrm_preview数据库及角色、外部副作用关闭、已有虚构标记和身份，再新增本次拥有的虚构资料。重复执行保留既有样例，拒绝接管不完整或未知夹具。
- 已准备：2个专用虚构主体、3名无钉钉绑定的虚构员工、2035-11归属/2035-12发放的2个试算批次及1个已批准验证批次。日期仅为隔离样例，不是正式工资月份。
- 准备中通过真实HTTP完成标准/规则生效、明确零期初、自然月考勤输入及封账、计算与复核审批。准备前后原payroll_preview_fixture_v1及其标准/规则/批次/考勤/授权指纹一致。
- 运行检查：`node scripts/verify-payroll-deductions-preview.cjs`。令牌仅驻留容器进程内，不写文件；检查前后所有隔离薪酬表及3项标记的指纹。
- 真实页面：`HRM_PAYROLL_DEDUCTIONS_ACCEPTANCE=1 npx playwright test --config playwright.preview.config.ts payroll-deductions.spec.ts`，只连接localhost:5173真实后端；单独的Web组件测试使用替代HTTP，不冒充真实集成。
