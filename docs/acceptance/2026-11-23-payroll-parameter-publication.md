# 工资参数主管审核与版本发布：隔离预览

## 范围和业务决定

用户确认：真实数据由HR录入，其主管审核，开发阶段先造数据。本轮只开发工资标准/主体规则的维护发布，不读取或修改真实工资，不改钉钉后台/通知、不授权或开启正式薪酬、不部署生产；产品仍0.9.2。参数审核是对录入依据的核对，不代替调薪决策和工资批次的复核审批。

流程：`HR保存草稿 → 提交自己的直属主管 → 退回修改/撤回重提，或审核发布 → 按生效日参与核算`。

## 实现与证据

| 项目 | 实现/验证 |
|---|---|
| 指定审核人 | 取HRM当前直属主管，提交快照冻结；缺少、自指、离职/停用、关系变化均不回退到管理员或随意改派。HR可撤回重提。 |
| 权限隔离 | HR需主体payroll_edit；主管派生的参数审核权只看明确分配记录。真实HTTP验证：主管无工资全集、批次及导出权；无授权管理员、自审、撤销HR授权及关系变化均拒绝。 |
| 历史与防绕过 | 记录每次提交/退回/撤回及快照/前版指纹；旧activate返回409，受管版和被替代版不可直接停用。通过不改旧版本定义/日期，旧工资批准快照保留。 |
| 生效 | 未来日期前不影响原月份，同日更高版可替代，早于发布末端插入阻断；新版到期不复活旧标准。真实PG读取版本链、HTTP重算旧月、单测覆盖连续版本/未关联重叠/异常链。 |
