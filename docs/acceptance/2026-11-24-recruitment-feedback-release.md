# 招聘协作与简历资料修复

日期：2026-11-24。产品版本0.9.2。用户明确要求修复后直接上线。

## 范围及决定

- 简历支持明确性别、出生年/月和注明年龄，贯通解析、回填、人工补充、保存与详情。年月保留精度，年龄保留“简历注明年龄”及记录时间，不从姓名、照片推断性别，不用年龄倒推生日或把旧年龄显示成当前实龄。新增三列可空，不批改旧资料。
- 四个用户指定协作账号增加独立`recruitment_view`，不改系统角色，不恢复档案、组织或绩效以外的能力。应聘/面试默认全部授权记录，保留个人筛选。对象和简历只读不包含编辑、删除、录用确认、管理分享或整表导出；原档案编辑/审核人员的导出资格保留。
- 录用确认只保留现有负责人独立确认，不新增确认人，不开放自审，不改现有申请提交人/状态。经办提交后交负责人；负责人本人提交的旧申请不能以本轮授权自审。
- 同一面试提供候选人版及面试官版复制内容，共用安排时间和会议URL。面试官版含获授权的本场安排/本人反馈入口；候选人版不自动复制内部备注或其他人评价。复制不代表已送达，不新建会议、不启用钉钉日程或外部消息。
- 修复应聘详情编辑无响应、本人反馈入口落错队列。人事通过/退回均绑定所见申请版本；409保留现场和退回意见、不自动重试新版本，批量按实际成功/失败反馈。
