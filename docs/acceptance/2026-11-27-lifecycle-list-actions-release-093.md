## 交付行为

- 目标台账、目标变更、改进计划、转正管理在PC操作列和手机操作区提供后端允许的“终止/删除”，原详情、原因、版本校验、403/409保留填写及数据范围保持。紧凑列表不逐行查询审计，不给普通参与人新增管理权。
- 周期与计划先终止，再从操作列删除；删除同时逻辑删除所属已结束任务及相关已结束目标变更，原业务状态、内容、得分和审计保留。任一未办结的受保护结果或目标变更存在，整批不删；事务内重核当前权限、原归属和完整影响hash，防止部分成功与重复。
- 未启动空草稿沿原编辑资格，原DELETE接口也改逻辑删除。默认正常列表不显示已删除，可在原授权范围选择“已删除/全部记录”；不开发恢复或物理清理。
- 删除前用原归档格式补存最终有效结果，不覆盖既有归档；普通自动归档同序加锁，锁后重核已删除周期，不再对旧候选继续写入。改进计划删除末页唯一记录后自动回到有效页，筛选保持。
- 指定绩效专员原角色、canViewAll、其他能力和周期归属均不变。之前已追加的两项生命周期能力保留；本次使用原可审计授权服务，仅为原指定两位HR追加`cycle_delete`，每人一条权限更新审计。HR/管理员不隐含获得已启动周期删除权。
- 不级联删除独立改进计划、转正、人员任职或薪酬结果，不代替审批、公示、申诉或真实业务签收。
